# Dashboard UI Explorer

A personal gallery of dark-mode dashboard UI templates — built to browse and explore design patterns.

## Dashboards

| Template | Description |
|---|---|
| **Analytics** | KPIs, traffic trends, channel breakdown, activity log |
| **Finance** | Net worth, portfolio allocation, cash flow, holdings |
| **Life OS** | Goals, habit tracker, mood log, task list |

## Stack

Pure HTML, CSS, and JavaScript — no frameworks, no build step. Charts powered by [Chart.js](https://www.chartjs.org/) via CDN.
